## 📌 About the Project

This project connects sales data from SQL Server with Power BI. The data is cleaned using Power Query and analyzed using DAX to create an interactive dashboard.

## 🔍 Key Areas Analyzed

* Daily sales and order performance
* Product-wise sales
* City-wise sales
* Order and shipping status
* Payment methods
* Stock information

## 🛠️ Technologies Used

Power BI | SQL Server | DAX | Power Query | GitHub

## 📚 What I Learned

Through this project, I gained practical experience in SQL Server, Power BI, DAX, data modeling, and creating interactive dashboards from relational data.
